01. Temperature & Humidity Monitoring

Arduino-based system using a DHT11 sensor to measure temperature and humidity and display the readings on an LCD.

02. Ultrasonic Distance Measurement

Arduino-based distance measurement system using an HC-SR04 ultrasonic sensor with real-time distance display.

03. Servo Motor Control

Arduino system controlling a servo motor from 0 to 180 degrees using a potentiometer.

04. Automatic Lighting System

Arduino-based automatic lighting system using an LDR sensor to detect ambient light and control an LED.
